## 📱 How to Use (Super Simple!)

### Live Detection:
1. Click "Start Listening"
2. Make a sound (talk, clap, play music)
3. See what sound was detected
4. Click "Stop Listening" when done

### Upload File:
1. Click "Browse files"
2. Select an audio file (WAV, MP3, etc.)
3. Click "Analyze Audio"
4. See the results!
